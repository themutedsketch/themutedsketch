01 / PROFILE

I'm an Electronics & Communication Engineering graduate working across embedded systems, robotics, electronics, automation, and hardware-software integration.

I'm a Robotics Trainer and Director of Core Systems at Spaceborn. My engineering interests sit close to the physical system: microcontrollers, sensors, actuators, control logic, circuit design, prototyping, and the firmware that connects everything together.

I like building from the bottom up — understand the signal, design the circuit, write the firmware, test the behavior, then iterate.

Engineering mindset: make it work → make it reliable → understand why.
